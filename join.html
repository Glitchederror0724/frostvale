JOIN FROSTVALE

Connect in a few clicks.

Choose your edition below. FrostVale supports Java and Bedrock players.

JAVA EDITION

frostvale.seedloaf.gg

  1. Open Minecraft: Java Edition.
  2. Select Multiplayer.
  3. Choose Add Server.
  4. Paste frostvale.seedloaf.gg.
  5. Join FrostVale.
BEDROCK EDITION

frostvale.seedloaf.gg

Bedrock uses FrostVale's Geyser/Floodgate setup. Because the public Bedrock port can change when the server host remaps ports, check the Discord for the current Bedrock port before connecting.

  1. Open Minecraft: Bedrock Edition.
  2. Go to Play → Servers → Add Server.
  3. Use frostvale.seedloaf.gg as the address.
  4. Enter the current Bedrock port announced in Discord.
