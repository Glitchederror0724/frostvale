# FrostVale Website v2

Multi-page static website made for GitHub Pages.

## Pages
- `index.html` — Home
- `join.html` — Java & Bedrock joining guide
- `ranks.html` — Player ranks and planned perks
- `rules.html` — Server rules
- `staff.html` — Staff page
- `appeal.html` — Appeal information

## Publish the update

1. Open your `frostvale` GitHub repository.
2. Replace the old site files with the files from this ZIP.
3. Commit the changes to `main`.
4. GitHub Pages should redeploy automatically.

## Important edits

### Bedrock port
The site intentionally tells Bedrock players to check Discord for the current port because Seedloaf may remap it. When you know you want a fixed public port displayed, edit `join.html`.

### Staff
Edit `staff.html` and replace the placeholder Admin/Moderator cards.

### Planned rank perks
Some homes/RTP perks on `ranks.html` are marked as planned because FrostValeCore is not live yet.

### Server status
The home page uses `api.mcsrvstat.us` from the browser to show online/offline and player counts.
